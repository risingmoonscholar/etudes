stash · v0.5.4 candidate

stash v0.5.4 candidate — external journal key and bounded progress

  • ETUDE_JOURNAL_KEY supports encrypted stash recovery when the login keychain is unavailable. Invalid supplied keys refuse without fallback; retain the same key for recovery.
  • Long stash and pop operations report bounded progress on stderr, keeping machine-readable stdout separate.

JSON migration: this candidate uses result envelope schema_version: 2. Consumers must check that version and read operation fields under details; they moved there from the top level. Capability-contract versions are separate.
