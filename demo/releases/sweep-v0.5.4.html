sweep v0.5.4 candidate — existing-folder routing and bound plans

Route eligible files into existing folders with a reviewable profile.

  • --scheme existing reads a versioned profile and uses only folders already present in the selected directory. Missing or ambiguous routes stay put, and safety refusals still win.
  • Exported plans bind the reviewed filesystem observations. Changed observations or an existing-folder profile change require replanning before apply.
  • Opt in to versioned progress records on stderr with --progress-json; --json stdout remains one result envelope. No speed improvement is claimed.

JSON migration: this candidate uses result envelope schema_version: 2. This is a breaking change for scripts and agents. Consumers must check that version and read operation fields under details; they moved there from the top level. Capability-contract versions are separate.
