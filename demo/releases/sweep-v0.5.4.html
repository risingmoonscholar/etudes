sweep v0.5.4 candidate — existing-folder routing and bound plans

Route eligible files into existing folders with a reviewable profile.

  • --scheme existing reads a versioned profile and uses only folders already present in the selected directory. If a route's folder is missing, sweep refuses and names it; it does not send those files to a folder you did not name. Duplicate or malformed routes refuse before anything moves, and safety refusals still win.
  • A file already inside its route's folder is reported as in place and is not proposed again.
  • Exported plans bind the reviewed filesystem observations. Changed observations or an existing-folder profile change require replanning before apply.
  • The scan says that applying reads the first and last 4 KiB of each file it moves, so undo can tell if a file changed. With --no-journal sweep reads no file bytes.
  • Undo leaves in place a folder that sweep did not create. Before each move, sweep checks that the destination folder is still the one it planned for and stops if it was replaced.
  • Opt in to versioned progress records on stderr with --progress-json; --json stdout remains one result envelope. No speed improvement is claimed.

JSON migration: this candidate uses result envelope schema_version: 2. This is a breaking change for scripts and agents. Consumers must check that version and read operation fields under details; they moved there from the top level. Capability-contract versions are separate.
