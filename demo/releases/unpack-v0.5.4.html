unpack v0.5.4 candidate — verified quarantine preservation

Unpack preserves the source archive’s download quarantine on the final extracted tree.

  • Captures quarantine from the same source descriptor used for the private archive copy; a changed attribute during copying refuses.
  • Applies the captured attribute to final files and directories, including the destination root, and verifies exact readback before publication. An unmarked archive adds no mark.
  • Publishes only after staging, tree audit and quarantine preservation pass. Preservation failure refuses and reports cleanup state; AppleDouble companions are retained where needed for attributes.
  • The extraction budget remains a monitored soft limit, not a hard write-time cap.

JSON migration: this candidate uses result envelope schema_version: 2. This is a breaking change for scripts and agents. Consumers must check that version and read operation fields under details; they moved there from the top level. Capability-contract versions are separate.
