sweep v0.5.3 — safer holds and bounded progress

Project documents inside child folders now hold related sibling assets without blocking unrelated files. This release also adds:

  • Content-inspection buffers erase their full allocation when dropped.
  • ETUDE_JOURNAL_KEY supports encrypted undo when the login keychain is unavailable. Invalid supplied keys refuse without fallback; retain the key for undo.
  • The cross-device copy fallback refuses NFC/NFD-equivalent destination collisions without changing either original.
  • Long apply and undo operations report bounded progress on stderr, keeping JSON output on stdout. The 9,999-file scenario checks that progress reaches the final item and stays within ten milestones.
